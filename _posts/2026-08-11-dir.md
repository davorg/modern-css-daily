The `:dir()` functional pseudo-class selects elements according to their directionality. Its most common forms are `:dir(ltr)` for left-to-right content and `:dir(rtl)` for right-to-left content.

Unlike an attribute selector such as `[dir="rtl"]`, `:dir(rtl)` does not require the selected element to have a `dir` attribute itself. It matches the directionality determined by the document language, including direction inherited from an ancestor. In HTML, this can also involve features such as `dir="auto"` and the `<bdi>` element.

```html
<nav dir="rtl">
  <a class="next" href="/next">
    Next <span aria-hidden="true">→</span>
  </a>
</nav>
```

```css
.next:dir(rtl) span {
  transform: scaleX(-1);
}
```

Here, the link matches `:dir(rtl)` because it is inside an element whose HTML direction is right-to-left. By contrast, `.next[dir="rtl"]` would not match because the link has no `dir` attribute of its own.

This is useful for interfaces that support both left-to-right and right-to-left languages. CSS logical properties—such as `margin-inline-start`, `padding-inline-end`, and `border-inline-start`—should usually handle directional spacing and layout. However, some visual details need an explicit directional rule. Common examples include mirroring arrows, changing directional icons, or adjusting a component whose visual meaning depends on reading direction.

The pseudo-class is defined in the Selectors Level 4 specification. That specification is still published as a draft, so it should be treated as evolving standards work rather than a permanently frozen definition. Avoid attaching the feature to an invented “introduction date”; standards and browser implementations develop on separate timelines.

One important caveat is that `:dir()` uses directionality as defined by the document language. Setting the CSS `direction` property does not determine whether an element matches `:dir(ltr)` or `:dir(rtl)`. In HTML, prefer the `dir` attribute when expressing the semantic direction of content.

Browser support can also vary across the browsers, embedded webviews, and older environments a project targets. Check current compatibility information and test in your supported environments. If you need a fallback based on `[dir="rtl"]`, remember that an attribute selector only finds explicit attributes and does not reproduce `:dir()`’s inherited or automatically determined behavior.

The CSS `hyphens` property controls whether browsers may hyphenate words when wrapping text across lines. Hyphenation can improve readability in narrow columns by reducing large gaps and avoiding awkwardly ragged line endings.

`hyphens` is defined in CSS Text Module Level 3, a W3C standards-track specification. The linked specification is an Editor’s Draft, so it should not be treated as an immutable final document, but the property uses established, unprefixed CSS syntax.

The property accepts three values:

- `none` prevents words from being hyphenated, including at explicitly indicated opportunities.
- `manual`, the initial value, allows hyphenation only where the text contains an explicit opportunity, such as a soft hyphen.
- `auto` also allows the browser to find language-appropriate hyphenation points automatically.

A minimal example looks like this:

```html
<p class="summary" lang="en">
  Internationalization can produce challenging line lengths.
</p>
```

```css
.summary {
  max-width: 24ch;
  hyphens: auto;
}
```

The `lang` attribute is important. Automatic hyphenation depends on the language of the text, and user agents may rely on language-specific dictionaries or other hyphenation resources. Set the language on the document or on the relevant element; do not expect reliable results from `hyphens: auto` when the language is unknown or incorrectly declared.

Hyphenation is especially useful in responsive layouts, cards, sidebars, multicolumn text, and other places where line lengths can become short. It can reduce overflow and improve the visual balance of paragraphs without inserting visible hyphens directly into the source. It also works well as progressive enhancement: if automatic hyphenation is unavailable, ordinary text wrapping still applies.

There are important caveats. The specification does not require every browser to choose identical hyphenation points. Results can vary with the user agent, language, writing system, installed resources, and platform. Some languages may have no suitable automatic hyphenation resource. The property permits hyphenation opportunities; it does not guarantee that a particular word will be split or that text can never overflow. Authors should test their actual content in their target browsers and avoid relying on hyphenation as the only overflow strategy.

`oklab()` is a CSS color function for expressing colors in the Oklab color space. Oklab is designed to be perceptually uniform: similar numerical changes should produce roughly similar-looking changes in color. Its three channels represent lightness (`L`) and two opponent color axes (`a` and `b`), with an optional alpha value.

The function is defined in CSS Color Module Level 4. It is standards-track CSS rather than a vendor-specific extension, but the linked CSSWG specification is still a draft, so details remain subject to the standards process.

A minimal declaration looks like this:

```css
.notice {
  color: rgb(145 70 110);
  color: oklab(55% 0.12 -0.04 / 90%);
}
```

The first value is a fallback. Browsers that understand `oklab()` use the second declaration; browsers that do not should ignore it and retain the preceding `rgb()` value.

The syntax uses spaces between the three channels and an optional slash before alpha. Here, `55%` is lightness, `0.12` and `-0.04` are the `a` and `b` coordinates, and `90%` is opacity.

Why use Oklab today? Traditional RGB values describe device-oriented color components, so changing each component by the same amount does not necessarily create a visually even change. Oklab is better suited to tasks where perceived relationships matter: generating lighter or darker variants, building coherent design-system palettes, and interpolating between colors without some of the unintuitive shifts associated with other spaces.

There are caveats. Perceptual uniformity is an approximation, not a guarantee that every numerical adjustment will look identical in every context. Oklab can also describe colors outside a display’s available gamut. Such colors may need gamut mapping and can appear different across devices.

Browser support should be checked against the requirements of your project rather than assumed. If unsupported browsers matter, provide a conventional color declaration first, as in the example, and test the rendered result on relevant devices. Also remember that Oklab coordinates are not interchangeable with Lab, RGB, or HSL coordinates; converting between spaces requires proper color conversion, not simply copying numbers.

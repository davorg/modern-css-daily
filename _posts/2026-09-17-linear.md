CSS `linear()` defines an easing curve from a list of points connected by straight-line segments. Unlike the `linear` keyword—which represents constant-rate progress—`linear()` can describe custom acceleration, deceleration, bounce, overshoot, and other complex motion.

The function is defined in **CSS Easing Functions Level 2**, currently an ongoing CSS Working Group draft. Its syntax may still evolve, so consult the specification and test support in your target browsers.

Each comma-separated point contains an output progress number and may include one or two input progress percentages. When percentages are omitted, CSS distributes those points across the remaining input-progress range.

```css
.card {
  transition: transform 400ms;
  transition-timing-function:
    linear(0, 0.8 60%, 1);
}

.card:hover {
  transform: translateY(-1rem);
}
```

Here, the transition begins at output progress `0`, reaches `0.8` after 60% of the transition’s duration, and then reaches `1` at the end. The browser interpolates linearly between those points.

This is especially useful for curves that are difficult or impossible to express accurately with a single `cubic-bezier()`. For example, a spring-like curve can be sampled into many points and represented directly in CSS. That lets developers use curves produced by design or animation tools without running JavaScript on every frame. The function works anywhere an easing function is accepted, including animation and transition timing functions.

There are some caveats. `linear()` does not calculate spring physics; it only follows the points you provide. A convincing spring or bounce may require a long list of sampled values, which can make stylesheets harder to read and maintain. Too few points can also make the changes between line segments noticeable.

Browser support is not universal, so keep a conventional easing as a fallback and optionally use a feature query:

```css
.card {
  transition-timing-function: ease;
}

@supports (transition-timing-function: linear(0, 1)) {
  .card {
    transition-timing-function:
      linear(0, 0.8 60%, 1);
  }
}
```

Also test curves with the properties you animate. Output values can extend beyond the usual `0` to `1` range, but the visible result depends on how the animated property is interpolated or constrained.

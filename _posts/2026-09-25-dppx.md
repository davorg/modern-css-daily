`dppx` is a CSS resolution unit meaning “dots per CSS pixel.” It expresses the relationship between an output device’s dots—typically device pixels on a screen—and CSS pixels. The unit is defined so that:

- `1dppx` equals `96dpi`
- `2dppx` equals `192dpi`

Its most common use is in resolution media queries, where styles can respond to the output device’s effective pixel density:

```css
.logo {
  background-image: url("logo.png");
}

@media (min-resolution: 2dppx) {
  .logo {
    background-image: url("logo-high-resolution.png");
  }
}
```

Here, `logo.png` is the default. When the output resolution is at least two dots per CSS pixel, the higher-resolution image is used instead. Keeping the default declaration outside the media query also provides a straightforward fallback.

This is useful for serving sharper raster graphics on high-density displays without changing their intended CSS size. It can help logos, icons, textures, and other pixel-based artwork look crisp while avoiding a larger asset on devices that do not need it. Resolution queries can also be used to adjust rendering details that would otherwise appear too thin or coarse at a particular pixel density.

The important distinction is that `dppx` describes resolution relative to a CSS pixel. It is not a direct measurement of a screen’s physical size, and `1dppx` should not be interpreted as a promise that one CSS pixel maps to a particular real-world length. CSS pixels are abstract units, and factors such as device behavior and zoom can affect their relationship to physical pixels.

There are also practical caveats. Higher-resolution images usually contain more data, so selecting them can increase download size and memory use. Test whether the visual improvement justifies that cost. Do not assume resolution alone captures every device characteristic relevant to your design. As with any CSS feature, verify behavior in the browsers and embedded web views your project supports rather than relying on guessed version numbers or support percentages.

`dppx` is defined in CSS Values and Units Level 4. The linked specification is an evolving CSS Working Group draft, so Level 4 as a whole should not be treated as a permanently frozen document.

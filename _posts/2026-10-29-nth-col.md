`:nth-col()` is a structural pseudo-class for selecting table cells according to the columns they occupy. Unlike `:nth-child()`, which counts sibling elements in the DOM, `:nth-col()` counts columns defined by the table’s column structure.

Its argument uses the familiar `An+B` notation. For example, `2n` selects every even-numbered column:

```html
<table>
  <tr>
    <td>A1</td>
    <td>A2</td>
    <td>A3</td>
    <td>A4</td>
  </tr>
  <tr>
    <td>B1</td>
    <td>B2</td>
    <td>B3</td>
    <td>B4</td>
  </tr>
</table>
```

```css
td:nth-col(2n) {
  background: #eef6ff;
}
```

In this table, the cells in the second and fourth columns receive the background color.

The important distinction is that column membership is not necessarily the same as sibling position. Tables can contain row groups, different element arrangements, and cells that span multiple columns. The specification defines `:nth-col()` in terms of the columns to which a cell belongs. A cell spanning several columns can therefore match if any of those columns satisfies the formula.

This makes the feature particularly useful for striped columns, emphasizing recurring data intervals, or styling a logical column without adding classes to every cell. It also expresses the author’s intent more accurately than selectors based on `:nth-child()`, which can produce incorrect results when rows have different structures or use `colspan`.

`:nth-col()` is defined in the Selectors Level 4 draft. It should therefore be treated as an emerging standards feature rather than something that can be assumed to work in every browser. Check current compatibility information and test it in the browsers required by your project; do not rely on it as the only way to communicate essential information.

It can still be useful today as progressive enhancement. Provide a readable default table style, then add column-specific decoration where the selector is supported. Keep rules containing `:nth-col()` separate from selector lists containing critical fallback selectors, because an unsupported selector can invalidate the whole selector list.

A related pseudo-class, `:nth-last-col()`, performs the same kind of matching while counting from the end of the column sequence.

`rlh` is a font-relative CSS length unit based on the root element’s line height. `1rlh` equals the computed value of `line-height` on the document’s root element—typically `<html>`. It is the line-height counterpart to `rem`, which is based on the root element’s font size.

The unit is defined in CSS Values and Units Module Level 4. That module remains a draft, so details can still change before becoming a finalized W3C Recommendation. The specification also defines special handling to avoid circular dependencies when `rlh` is used in the root element’s own `font-size` or `line-height`.

A minimal example looks like this:

```css
:root {
  font-size: 1rem;
  line-height: 1.5;
}

article {
  margin-block: 2rlh;
  padding-block: 1rlh;
}
```

If the root font size resolves to `16px`, a unitless `line-height` of `1.5` produces a root line height of `24px`. In that situation, `1rlh` resolves to `24px` and `2rlh` to `48px`.

This is particularly useful for establishing a consistent vertical rhythm. Margins, padding, gaps, and other dimensions can align with the document’s baseline text spacing without repeating a fixed length throughout the stylesheet. If the root typography changes—for example, in a responsive design—the spacing expressed in `rlh` changes with it.

Unlike `lh`, which is relative to the line height of the element where it is used, `rlh` always refers to the root line height. That makes `rlh` useful for page-level spacing and shared layout rules, while `lh` may be a better choice for components that should follow their own typography.

There are some caveats. Browser support should be checked for the environments your project targets rather than assumed. A conventional fallback can be placed before the `rlh` declaration:

```css
article {
  padding-block: 1.5rem;
  padding-block: 1rlh;
}
```

Also, when the root uses `line-height: normal`, the specification requires `normal` to be converted to an absolute length using font metrics. The resulting value can therefore vary with the selected font and user agent. Finally, sizing something in `rlh` does not guarantee that every rendered line box has exactly that height; inline content and other layout details can affect actual line boxes.

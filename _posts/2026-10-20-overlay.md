The CSS `overlay` property controls whether an element placed in the [top layer](https://drafts.csswg.org/css-position-4/#top-layer)—such as an open popover or modal `<dialog>`—is rendered there. Its current grammar is `none | auto`.

Authors cannot use `overlay: auto` to move arbitrary elements into the top layer. The browser controls the property’s effective value as elements enter and leave that layer. Its practical purpose for authors is as a discrete transition property: transitioning `overlay` can keep a closing element in the top layer until its exit animation finishes.

Here is a minimal popover example:

```html
<button popovertarget="menu">Toggle menu</button>
<div id="menu" popover>Menu content</div>
```

```css
[popover] {
  opacity: 0;
  transition:
    opacity 200ms,
    display 200ms allow-discrete,
    overlay 200ms allow-discrete;
}

[popover]:popover-open {
  opacity: 1;
}

@starting-style {
  [popover]:popover-open {
    opacity: 0;
  }
}
```

When the popover opens, `@starting-style` supplies the initial opacity so it can fade in. When it closes, the discrete `display` and `overlay` transitions are deferred until the end of the transition. That allows the popover to remain rendered—and remain above ordinary document content—while its opacity fades out.

Without this behavior, removing a popover or modal dialog from the top layer can make an exit animation disappear immediately or render incorrectly relative to the rest of the page. `overlay` therefore addresses a common problem with animating UI that the browser itself promotes into a special rendering layer.

`overlay` is defined in the CSS Positioned Layout Module Level 4 Editor’s Draft. It is draft technology rather than a finalized web standard, so details may still change. Implementation may also vary across browsers. In particular, the complete example depends not only on `overlay`, but also on discrete transitions, `transition-behavior: allow-discrete`, `@starting-style`, and the Popover API.

Treat these animations as progressive enhancement. The popover should remain usable if some animation-related declarations are ignored, and production code should be tested in the browsers your project supports. Also remember that `overlay` is not a general-purpose stacking or positioning tool; use `z-index` and normal positioning for elements that are not managed through a top-layer feature.

CSS `hwb()` expresses colors using **hue**, **whiteness**, and **blackness**. It offers an intuitive way to start with a hue and then tint it with white or shade it with black.

The function is defined in the W3C’s standards-track **CSS Color Module Level 4** specification. Its exact publication status may change as the specification progresses, so consult the document’s “Status of This Document” section for the current maturity level.

A minimal example uses space-separated components, with an optional alpha value after a slash:

```css
.badge {
  background-color: hwb(210deg 20% 10% / 80%);
}
```

Here, `210deg` selects a hue from the same color wheel used by `hsl()`. The next two values add 20% whiteness and 10% blackness. The optional `80%` alpha value makes the resulting color partially transparent.

Conceptually, `hwb()` is useful because its controls often match how people describe color adjustments. Increasing whiteness produces a lighter tint, while increasing blackness produces a darker shade. This can make related UI colors and design tokens easier to read and edit than equivalent RGB channel values:

```css
:root {
  --brand-light: hwb(210deg 45% 5%);
  --brand-base:  hwb(210deg 10% 10%);
  --brand-dark:  hwb(210deg 5% 45%);
}
```

There are several caveats. HWB is not perceptually uniform, so changing whiteness or blackness by equal numerical amounts does not guarantee equally noticeable visual steps. It also does not provide access to a wider gamut than sRGB.

Whiteness and blackness interact when their sum reaches or exceeds 100%. In that case, they are normalized so that their sum becomes 100%, producing an achromatic color; the hue no longer affects the result. This can make accidentally large channel values look different from what an author expected.

Finally, support requirements depend on your project’s browsers, embedded webviews, and other rendering environments. Check current compatibility data rather than relying on a particular version claim. If unsupported clients matter, place a conventional fallback declaration before the `hwb()` declaration so they can retain the earlier value.
